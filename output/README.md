# herdr

An agent multiplexer that lives in your terminal — a terminal workspace manager
for AI coding agents.

- Upstream project: <https://github.com/ogulcancelik/herdr>
- Website: <https://herdr.dev>

## What is herdr?

herdr lets you run and orchestrate multiple AI coding agents side by side from a
single, keyboard-driven terminal UI. It manages workspaces, sessions and remotes
so you can drive a whole fleet of agents without leaving your terminal.

## Usage

```sh
herdr
```

See `herdr --help` for the full command line reference, or visit
<https://herdr.dev> for documentation.

## Packaging

This is the _unofficial_ Debian/Ubuntu package for herdr, hosted at
[deb.griffo.io](https://deb.griffo.io). It repackages the upstream release
binary; for the herdr source code and issues, see the upstream repository above.
